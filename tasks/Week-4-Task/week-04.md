## Goal for the Week

This week focuses on completing the **display pipeline**, implementing the **memory module**, and building a **minimal GUI interface** for visualization.  
By the end of the week, your emulator should render basic CHIP-8 graphics and support memory-backed instruction/data access.

---

## Part A – Display Module

Design a module that supports the CHIP-8 64×32 monochrome display.

- Accept draw command inputs from the CPU (via `DXYN` opcode)
- Maintain a 64×32 pixel framebuffer
- Support collision detection (i.e., when a pixel is unset during XOR draw, set VF to 1)
- Provide a `chip8_display.v` module with a simple pixel-access interface

## Part B – Memory Module

Create a memory module that behaves like a unified RAM for both code and data.

- 4KB memory with byte-level addressing (12-bit)
- Should support read/write for both CPU and display
- ROM is preloaded into memory at address `0x200`


## Part C – Minimal GUI Interface

Your goal is to implement a lightweight, shell-driven GUI interface to simulate and visualize CHIP-8 graphics output.

We are trying to include a retro-style Python GUI shell that:

- Lets you select from a list of classic CHIP-8 games (ROMs)
    
- Launches a simulation in Vivado via `xsim`
    
- Periodically displays the output from simulation-generated framebuffer dumps
    

No actual gameplay is implemented. The goal is visualization only, not interaction.

---

### Features to Implement

- **Tcl Automation**:
    
    - Scripts to compile and simulate the design using Vivado `xsim`
        
    - Automatically generate or update a framebuffer dump file from simulation
        
- **Shell Commands** (inside your GUI shell of your choice):
    
    - `launch` — compile and start the simulation
        
    - `uptime` — display current simulation time or tick count
        
    - `exit` — cleanly terminate the shell
        

> [!NOTE]  
> This GUI is not interactive, it is purely for simulation-based output viewing. You cannot play the game :( only observe draw behavior.
